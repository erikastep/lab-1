# Lab 1 – Steering: Code vs Graph & Flocking

Team: Erika Steponavičiūtė, Gabrielė Sabuckytė, Bianca Meknat
Unity version: 6000.6.4f1

## How to run
1. Clone the repo and open the folder in Unity Hub (Add project from disk).
2. Open `Assets/_Project/Scenes/Lab1_Main.unity` and press Play.

Controls: arrow keys move the player, keys 1–4 switch the camera (code agent, graph agent, flocking, all).
